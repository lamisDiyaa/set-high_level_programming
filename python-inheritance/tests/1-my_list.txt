===========================
How to Use 1-my_list.py
===========================

This module defines a class `MyList` that inherits from `list`.

Usage
=====

Import the class:
    >>> MyList = __import__('1-my_list').MyList

Create an instance and append elements:
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Print sorted version:
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

Ensure original list is unchanged:
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Empty list test:
    >>> my_list2 = MyList()
    >>> my_list2.print_sorted()
    []

Negative numbers:
    >>> my_list3 = MyList([-1, -5, 2, 0])
    >>> my_list3.print_sorted()
    [-5, -1, 0, 2]
